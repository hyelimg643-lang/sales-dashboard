# 대시보드 화면 구성 (dashboard_sketch.png의 텍스트 버전)

> 와이어프레임 이미지: `docs/dashboard_sketch.png`
> 색상과 세부 배치는 자유롭게 바꿔도 되지만, 탭 구성과 각 탭의 요소는 이 문서를 따른다.
> 화면 숫자는 더미데이터 2026-09 기준이며, `report_template.md` 2부와 같은 값이어야 한다.

## 공통
- 상단 제목: "영업 성과 분석 대시보드 (PoC · 더미데이터)"
- 좌측 사이드바 필터: 기준 월(기본 2026-09), 지점(기본 전체), 상품군(체크박스, 기본 전체 선택)
- 필터는 모든 탭에 공통 적용
- 탭 4개: ① 성과 대시보드 ② 위험 설계사 ③ 실적 예측 ④ 월간 보고서

## ① 성과 대시보드 (첫 화면)
1. KPI 카드 4개 (가로 한 줄)
   - 신계약 건수 + 전월 대비 증감률
   - 신계약 보험료 + 전월 대비 증감률
   - 목표 달성률(건수) + 목표 건수
   - 가동률 + "가동 인원 / 재직 인원"
2. 월별 신계약 추이: 24개월 선 그래프, 건수/보험료 전환 토글
3. 상품군별 비중(당월): 가로 막대
4. 지점별 실적 vs 목표(당월): 막대=실적, 점선=목표, 달성률 90% 미만 지점은 빨간색 + 달성률 표시

## ② 위험 설계사
1. 등급별 인원 카드 3개: 고위험(60점↑) / 관찰(30~59점) / 정상
2. 위험 설계사 목록 표 (점수 높은 순)
   - 컬럼: 설계사, 지점, 점수, 등급, 해당 사유, 직전3M→최근3M 건수, 유지율
   - 사이드바에 등급 필터 추가 (기본: 고위험+관찰)
   - CSV 다운로드 버튼
3. 표에서 설계사를 선택하면 아래에 상세 표시
   - 최근 12개월 월별 판매 건수 막대 그래프
   - (Nice-to-have) 본인 상품군 구성 vs 전사 평균 비교

## ③ 실적 예측
1. 지점별 다음 분기 예측 건수 막대 + 목표선, 예측 달성률 80% 미만 지점은 빨간색
2. 표: 지점, 예측, 목표(가정), 예측 달성률, 판정(정상 / ⚠ 괴리 예상)
3. "계산 근거" 펼쳐보기: 계절지수(10·11·12월), 지점별 최근 3개월 평균

## ④ 월간 보고서

2. `report_template.md` 구성대로 만든 마크다운 미리보기
3. "보고서 다운로드 (.md)" 버튼
