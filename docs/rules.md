# 업무 규칙 정의서 (PoC용)

> 이 문서의 기준값과 가중치는 PoC 시연을 위한 **가정치**이며 회사의 실제 기준이 아니다.
> 기준일은 **2026-09-30**으로 고정한다.

## 1. 기간 정의
| 용어 | 정의 |
|---|---|
| 당월 | 2026-09 |
| 최근 3개월 | 2026-07 ~ 2026-09 |
| 직전 3개월 | 2026-04 ~ 2026-06 |
| 최근 2개월 | 2026-08 ~ 2026-09 |
| 실적 집계 기준 | `contract_date`(계약일)의 연월 |

## 2. 집계 대상
- 실적 집계: 모든 신계약 (해지·실효 건도 신계약 실적에는 포함)
- 위험점수·가동률 대상 설계사: `agents.status = 재직`인 설계사만
- 신규 위촉자: 위촉 후 3개월 미만이면 위험점수의 "감소" 조건을 적용하지 않는다

## 3. 지표 계산식
| 지표 | 계산식 | 표시 |
|---|---|---|
| 신계약 건수 | 기간 내 계약 건수 | 건 |
| 신계약 보험료 | 기간 내 `monthly_premium` 합계 | 원 |
| 목표달성률 | 실적 ÷ `targets`의 목표 × 100 (건수·보험료 각각) | % |
| 가동률 | 해당 월 신계약 1건 이상인 재직 설계사 수 ÷ 해당 월 재직 설계사 수 × 100 | % |
| 유지율 | `status = 유지` 건수 ÷ 전체 신계약 건수 × 100 | % |
| 조기해지율 | 계약일로부터 90일 이내 해지·실효 건수 ÷ 전체 신계약 건수 × 100 | % |
| 승환계약 발생율 | `is_replacement = 1` 건수 ÷ 전체 신계약 건수 × 100 | % |
| 상품군 편중도 | 설계사의 최다 판매 상품군 건수 ÷ 본인 전체 건수 × 100 | % |
| 1인당 생산성 | 신계약 건수 ÷ 가동 설계사 수 | 건 |

- 유지율·조기해지율·승환율·편중도는 설계사별 전체 기간(24개월) 기준으로 계산한다
- 분모가 0이면 "-"로 표시한다

## 4. 위험점수 (0~100점)
| 조건 | 점수 | 표시 사유 |
|---|---|---|
| 최근 3개월 건수 ≤ 직전 3개월 건수 × 0.7 (직전 3개월이 1건 이상일 때만) | +30 | 판매 급감 |
| 유지율 80% 미만 | +25 | 유지율 저하 |
| 최근 2개월 신계약 0건 | +25 | 연속 무실적 |
| 상품군 편중도 70% 이상 | +10 | 상품 편중 |
| 조기해지율 10% 이상 | +10 | 조기해지 다발 |

| 등급 | 점수 | 조치 |
|---|---|---|
| 고위험 | 60점 이상 | 코칭·교육 대상 자동 추천 |
| 관찰 | 30~59점 | 지점장 모니터링 |
| 정상 | 30점 미만 | - |

화면에는 점수와 함께 **해당된 사유를 모두** 표시한다 (예: "판매 급감, 연속 무실적").

**검증용 기대 결과:** A015·A031·A044 = 90점, A007·A023 = 65점 (고위험 5명)

## 5. 예측
- 월 예측 = 최근 3개월 월평균 건수 × 계절지수
- 계절지수(월) = 전년 같은 달 전사 건수 ÷ 2025년 1~12월 전사 월평균 건수
  (예: 2026-10의 계절지수 = 2025-10 전사 건수 ÷ 2025년 월평균)
- 다음 분기(2026-10~12) 예측 = 각 월 예측의 합
- 지점별로 계산하며, 다음 분기 예측이 같은 기간 목표의 80% 미만이면 **"괴리 예상"**으로 표시
- 다음 분기 목표가 없으므로 PoC에서는 **최근 3개월 목표 평균 × 3**을 다음 분기 목표로 간주

## 6. 교차판매 기회 (시간 남으면)
- 설계사별 상품군 비중과 전사 평균 비중을 비교
- 전사 평균보다 15%p 이상 낮은 상품군을 "교차판매 추천 상품군"으로 표시

## 7. DB유입원천별 가동률 (시간 남으면)
- `agents.db_source`(자체개척/회사DB/제휴DB)별로 3번의 가동률을 계산해 비교

## 8. 월간 보고서 구성
선택한 월 기준으로 아래 순서의 마크다운을 생성한다.
1. 요약: 신계약 건수·보험료, 전월 대비 증감, 목표달성률, 가동률
2. 지점별 실적과 목표달성률 표
3. 상품군별 실적 표
4. 위험 설계사 목록 (고위험·관찰, 사유 포함)
5. 다음 분기 예측과 괴리 예상 지점
