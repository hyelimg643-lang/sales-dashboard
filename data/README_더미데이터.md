# 영업 성과 PoC 더미데이터 설명

모든 데이터는 가상입니다. 실제 회사, 설계사, 고객, 상품과 무관합니다.
- 기준일: 2026-09-30 / 기간: 2024-10 ~ 2026-09 (24개월)
- 인코딩: UTF-8 (BOM 포함, 엑셀에서 바로 열림)
- `generate_dummy_data.py`를 다시 실행하면 똑같은 데이터가 재생성됩니다 (seed 42)
