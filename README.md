# 영업 성과 분석 대시보드 (PoC · 더미데이터)

## 실행 방법
1. Python 3.10 이상을 준비한다.
2. 이 폴더에서 패키지를 설치한다.
   ```
   pip install -r requirements.txt
   ```
3. 앱을 실행한다.
   ```
   streamlit run app.py
   ```
4. 브라우저가 자동으로 열리지 않으면 http://localhost:8501 에 접속한다.

## 데이터 올리기
- 사이드바 맨 위 **데이터 올리기**에서 CSV를 올리면 그 데이터로 모든 탭을 다시 계산한다.
- 파일 이름은 `agents`, `branches`, `contracts`, `products`, `targets` (.csv) 중 하나여야 하고, 올리지 않은 파일은 `data/`의 기본 더미데이터를 쓴다.
- 열 구성은 **양식 내려받기**(현재 더미데이터 CSV 5개 + 설명)와 같아야 한다. 필수 열, 날짜·숫자 형식, 허용 값(재직/해촉, 유지/해지/실효, 종신/건강/연금/저축), ID 연결을 검사해 문제가 있으면 화면에 이유를 보여준다.
- UTF-8과 엑셀 기본 저장(CP949) 모두 읽는다. 올린 파일은 저장되지 않는다.
- 웹 공유 페이지에는 올리기 기능이 없다. 새 데이터로 웹 페이지를 갱신하려면 `data/`를 바꾸고 `python web/build_web.py`를 다시 실행한다.

## 구성
- `app.py`: 화면 (사이드바 필터, 탭 4개)
- `metrics.py`: 지표 계산 로직 (docs/rules.md 기준)
- `report.py`: 월간 보고서 마크다운 생성 (docs/report_template.md 구성)
- `data/`: 더미데이터 CSV 5개
- `docs/`: 규칙·화면 구성·보고서 양식
